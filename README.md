## Menjalankan

1. Pasang Go dari https://go.dev/dl, lalu cek di terminal: `go version`
2. Buka folder ini di VS Code, lalu buka terminal (menu Terminal → New Terminal).
3. Jalankan:

       go run .

Pakai `go run .` (dengan titik), bukan `go run main.go`, karena program ini terdiri dari dua file.

Folder `pertemuan1-final` berisi source lengkap sebagai pembanding: ketik sendiri dulu, baru bandingkan.
